## Where to stand

The placeholder gates are 85% of the way from the arena centre to each team
start — the ratio the surveyed arenas actually measure — so these land in
roughly the right doorway. Teleport there, then `.gps` the real spot.

## How to send a survey

For each arena, two gates and two shadowsight nodes:

```
.gobject add 185483        # at each gate, then .gobject near for the guid
.gps                       # standing on each shadowsight spot
```

Gate rotations are read from the `gameobject` rows, so the guids are enough —
`.gobject add` does not print orientation. If a gate is nudged after placing,
the DB position wins, not the one the add command echoed.

## Where the numbers live

| Stage | Location |
|---|---|
| Source of truth | `tools/arenas/gen_arena_sql.py` → `MEASURED` |
| Generated SQL | `sql/custom/world/2026_08_06_02_world_ported_arenas.sql` |
| Applied to | `lplusdevworld.battleground_custom_arena_object` |
| Read at runtime | `BattlegroundCustomArena::LoadObjects()` |

No coordinate is compiled into the C++. Adding a survey is an edit to
`MEASURED`, a regenerate, an apply, and `.reload battleground_template` —
never a rebuild.
