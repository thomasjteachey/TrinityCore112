## 2. Rules (pin in #name-the-bots)

> **HOW THIS WORKS**
>
> Each bot gets its own thread below. Reply in the thread with **one name**.
> Submit for as many bots as you like. React 👍 on names you want to see win —
> that's what decides the ten that make the poll.
>
> **A name has to be something the game will actually accept:**
> • 2–12 letters
> • A–Z only — no numbers, spaces, apostrophes or punctuation
> • no letter three times in a row (`Throgggg` is out)
> • not already taken by a character on the realm
>
> Anything that breaks those gets dropped automatically, so check before you post.
>
> **Schedule, every week:**
> • **Mon–Thu** — submit
> • **Fri** — top ten per bot go up as polls
> • **Sun night** — polls close, names go live in-game, winners get credited
>
> Straight vote, most votes wins. I'll veto a name only if it would get the
> realm in trouble, and I'll say so publicly when I do.
